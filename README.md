# Finder Image

Finder Image — это сервис для автоматического поиска изображений товаров по артикулу и производителю. Он поддерживает Google Custom Search и OpenAI Images, хранит результаты в PostgreSQL и предоставляет удобный web-интерфейс с панелью отладки и современным голубым оформлением.

## Основные возможности

- Авторизация (по умолчанию `admin/admin`) и изменение логина/пароля.
- Загрузка товаров из Excel (столбцы `sku` и `manufacturer`, поддерживаются русские названия колонок).
- Добавление товаров вручную.
- Поиск изображений в Google Custom Search или OpenAI Images для одиночных или множественных товаров.
- Просмотр превью изображений, выбор финального изображения и просмотр логов запросов/ответов.
- Панель пакетной обработки с выбором режима поиска и опциональным собственным запросом.
- История логов с сохранением запросов, ответов и ошибок.

## Стек

- FastAPI
- SQLAlchemy
- PostgreSQL
- Pandas / OpenPyXL для импорта Excel
- Встроенный фронтенд на чистом JavaScript

## Запуск через Docker Compose

```bash
docker compose up --build
```

Сервис будет доступен на `http://localhost:7000`. База данных слушает порт `5452` (хост) → `5432` (контейнер).

Переменные окружения можно задать через файл `.env` на основе `.env.example`:

```env
APP_SECRET_KEY=change-me
DATABASE_URL=postgresql+psycopg2://root:Admin2025@db:5432/finder_image
GOOGLE_API_KEY=...
GOOGLE_CSE_ID=...
OPENAI_API_KEY=...
```

> **Важно:** для работы поиска необходимо указать ключи Google Custom Search и OpenAI в `.env` или переменных окружения. Без них сервис сохранит подробный лог ошибки и сообщит о необходимости настроить ключи.

## Локальный запуск без Docker

1. Установите PostgreSQL (порт 5452, пользователь `root`, пароль `Admin2025`, база `finder_image`).
2. Создайте и активируйте виртуальное окружение Python 3.11.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 7000 --reload
   ```

## Структура проекта

```
app/
  ├── auth.py         # Аутентификация и работа с токенами
  ├── config.py       # Конфигурация и .env
  ├── database.py     # Подключение к БД
  ├── main.py         # Точки входа FastAPI
  ├── models.py       # SQLAlchemy-модели
  ├── schemas.py      # Pydantic-схемы

  └── static/         # Статические файлы UI (HTML/CSS/JS)
```

## Тестовые данные

- В базе автоматически создаётся пользователь `admin` с паролем `admin`.
- Для демонстрации работы достаточно добавить товары вручную, импортировать из Excel или использовать пакетный поиск.

## Журналы поиска

Каждый запрос к Google или OpenAI записывается в `search_logs` вместе с телом запроса и ответом/ошибкой. Логи доступны из интерфейса в панели деталей товара.
